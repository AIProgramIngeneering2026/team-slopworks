# Конвейер обработки документов

Сервис для пользователей, которым нужно получить текст из сканированного PDF через API. Пользователь отправляет документ, получает идентификатор задания и по нему запрашивает состояние, извлечённый текст или причину ошибки.

## Возможности

- Распознавание сканированных PDF через внешний OCR-сервис и сохранение извлечённого текста.
- Повтор запроса с тем же файлом, параметрами и ключом идемпотентности возвращает прежнее задание, включая одновременные запросы.
- Если ключ уже использован с другим файлом или параметрами, сервис возвращает ошибку конфликта `409`. Новое задание не создаётся, прежнее не изменяется.
- Проверка содержимого файла до создания задания. ZIP-архив, в том числе переименованный в PDF, отклоняется без обращения к OCR.
- Один повтор обращения к OCR при тайм-ауте. После двух тайм-аутов задание переходит в состояние «отклонён», сохраняется причина ошибки.

Исходные PDF хранятся в локальной файловой системе. Задания, пути к файлам и результаты обработки хранятся в БД.

## Ограничения

Проверка полноты распознавания по страницам не входит в первую версию. Результат распознавания возвращается обычным текстом. Сохранение оформления, выделение разделов и преобразование в Markdown не гарантируются.

## Стек

C#, .NET, ASP.NET Core, Entity Framework Core с миграциями, SQLite с переходом на PostgreSQL, xUnit.
